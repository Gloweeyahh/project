# Gloria Emeka Portfolio

A Vite + React portfolio site for Gloria Emeka, featuring services, case studies, proposals, contact flow, and a booking CTA.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Deployment

This project is configured for Netlify via `netlify.toml`.

- Build command: `npm run build`
- Publish directory: `dist`
